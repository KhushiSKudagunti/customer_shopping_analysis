# customer_shopping_analysis

Project Overview
The goal of this project is to simulate a corporate-grade end-to-end data analytics workflow, demonstrating the ability to translate raw data into strategic business intelligence by:

✅ Data Preparation,Modeling & Exploratory Data Analysis (Python): Clean and transform the raw dataset for analysis.

✅ Data Analysis (SQL): Simulate business transactions, and run queries to extract insights on customer segments, loyalty, and purchase drivers.

✅ Visualization & Insights (Power BI): Build an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.

## Project Workflow

### 1. Data Analysis using Python
Open `Customer_Shopping_Behavior_Analysis_khushi.ipynb`.

This notebook includes:
- Data import
- Data exploration
- Data cleaning
- Database connection

### 2. SQL Analysis
Load the cleaned data from the Python notebook into **MySQL / PostgreSQL / MS SQL Server**.

Steps:
- Create the SQL database
- Load the data using Python
- Open `customer_behavior_sql_queries.sql`
- Execute SQL queries to answer key business questions
- Analyze customer behavior, sales, and purchasing patterns

### 3. Power BI Dashboard
Connect the SQL database to Power BI.

Open `customer_behavior_dashboard.pbix` to explore the interactive dashboard, including:
- Customer insights
- Sales analysis
- Purchase behavior
- Interactive charts and filters
